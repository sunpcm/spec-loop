# 计数器演示

### [REQ-CNT-01] 计数器与自定义步长

#### 功能
- 页面展示计数值，初始值为 0。
- 输入合法整数步长后，点击“增加”按该步长累计。
- 提供“减少”按钮，与“增加”共用同一个步长输入，点击后按该整数步长减去计数。
- 提供“翻倍”按钮，点击后将当前计数值乘以 2，步长输入保持不变。
- 点击“重置”将计数值恢复为 0。

#### 验收
- 初始显示 0；步长 2 时点击一次显示 2。
- 步长 2 时，先点击“增加”得到 2，再点击“减少”回到 0。
- 初始为 0 时点击“翻倍”，计数仍为 0。
- 计数为 2 时点击“翻倍”，计数变为 4，且步长保持不变。
- 翻倍后点击“重置”显示 0，原步长保留。
- 增加、减少、翻倍共用步长输入；重置、需求 ID 和页面版本展示保持可用。
